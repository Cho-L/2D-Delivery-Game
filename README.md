# 2D-Delivery-Game
Unity 기반으로 제작한 2D 배달 게임 프로젝트입니다.  플레이어는 차량을 조작하여 패키지를 수집하고 목적지까지 배달합니다.

주요 기능
차량 이동 시스템
Input System 기반 이동 구현
회전 및 전진 이동 처리
충돌 시 속도 감소
특정 오브젝트 충돌 시 속도 증가
카메라 추적 시스템
LateUpdate 기반 카메라 추적 구현
Offset 적용
배달 시스템
Trigger 기반 패키지 수집
배달 상태 관리
상태에 따른 플레이어 색상 변경
사용 기술
Unity
C#
Rigidbody2D
Trigger / Collision System
개선 예정
Object Pooling 적용
ScriptableObject 기반 데이터 관리
UI 시스템 추가
사운드 추가
점수 시스템 구현
